## About Zosho
**Zosho** is a next-generation manga and webtoon reader built from the ground up for modern mobile devices. Designed with a focus on fluid animations, modular expansion, and absolute privacy, Zosho aims to provide the ultimate reading experience across Android and iOS.

---

## Core Projects

We are committed to building a transparent, open-source ecosystem. Explore our primary repositories:

### 📱 [Zosho App](https://github.com/zosho-app/zosho) *(Coming Soon)*
The main mobile application client. A beautifully crafted reader engineered for speed and aesthetic excellence.

### 🧩 [Zosho Extensions](https://github.com/zosho-app/zosho-extensions)
The community-driven repository for source plugins. These lightweight JavaScript modules execute safely within the app, keeping the core client fast and secure.

### 🌐 [Zosho Website](https://github.com/zosho-app/website) *(Coming Soon)*
The landing page and official documentation hub for readers and extension developers.
