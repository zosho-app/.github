## About Zosho

**Zosho** is a next-generation, high-performance manga and webtoon reader designed for modern Android devices. We built Zosho from the ground up to solve the performance bottlenecks of traditional mobile readers by combining a 120FPS GPU-accelerated canvas with a secure, modular extension ecosystem.

Our mission is to provide an unparalleled, premium reading experience featuring a minimalist dark-mode aesthetic, buttery-smooth UI animations, and advanced on-device processing.

### 🚀 The Tech Stack
* **Rendering Engine:** React Native Skia for hardware-accelerated 120FPS pinch-to-zoom and panning.
* **UI & Animations:** Reanimated 3 & Moti for fluid, native-thread gesture handling and component transitions.
* **Local Database:** WatermelonDB (SQLite) for instantaneous library reactive updates.
* **Extension Sandbox:** QuickJS WASM virtual machine for secure, isolated community scrapers.
* **Future-Proof:** Architected to support on-device C++ ONNX machine learning models for real-time AI manga colorization.

## Our Projects

At Zosho, we are committed to building a robust, open-source ecosystem. Here are our core repositories:

### 📱 [Zosho App](https://github.com/zosho-app/zosho)
The core mobile application. A beautifully crafted React Native client featuring our custom Skia viewer, reactive library, and customizable reading HUD.

### 🧩 [Zosho Extensions](https://github.com/zosho-app/zosho-extensions)
The community-driven marketplace of source scrapers. These lightweight JavaScript plugins execute securely inside Zosho's QuickJS sandbox, keeping the main app safe and performant.

### 🌐 [Zosho Website](https://github.com/zosho-app/website) *(Coming Soon)*
The landing page and official documentation for users and extension developers.
